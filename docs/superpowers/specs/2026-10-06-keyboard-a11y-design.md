# Keyboard + screen-reader accessibility — design

**Goal:** every board interaction works by keyboard alone and makes sense to a screen reader, before the public portfolio deploy.

**Scope (files):** `components/board/column.tsx`, `components/board/task-card.tsx`, `components/board/task-detail-dialog.tsx`, `components/layout/navbar.tsx` (+ the `user-menu.tsx` trigger it renders, + a new `components/layout/theme-toggle.tsx`), `app/(dashboard)/boards/boards-client.tsx`, `app/(dashboard)/board/[boardId]/board-view.tsx`, a new pure `lib/drag-announcements.ts`, tests, `CLAUDE.md`. **Not** `board-header.tsx` (another session owns it), not `components/ui/**` (generated), no migrations.

## Findings that shaped the design (verified in installed source)

| Area         | Fact                                                                                                                                                                                                                                                                                                                                                                                                         | Source                                                              |

On unmount (after the ~150 ms exit animation) FocusScope's `setTimeout(0)` cleanup refocuses the trigger — a second blur. ## Decisions

1. **Rename opens after the menu closes.** The item's `onSelect` only flags the request; `DropdownMenuContent onCloseAutoFocus` sees the flag, `preventDefault()`s the trigger refocus, and only then sets `isEditingTitle` — the input mounts with no focus trap and no pending refocus, and `autoFocus` sticks. Drop the `setTimeout`. A ref guard makes the blur that follows Enter/Escape a no-op (no double save, no save-on-cancel). Enter/Escape return focus to the menu button; a click-away blur leaves focus where the user put it.
2. **Column menu split from the "names" task.** The trigger name and rename-input name live in column.tsx, so they ship with the rename fix; that removes the names task's dependency on column.tsx and lets it run in parallel.
3. **Card = `role="button"` + `tabIndex=0` for everyone.** Enter opens (guarded: `!defaultPrevented`, `target === currentTarget`). Space opens for viewers (APG button behaviour; nothing to drag) and stays dnd's lift key for editors.
4. **Card name = its title** (`aria-labelledby`), details (priority, labels, due date, assignee) + dnd instructions in `aria-describedby`. Name-from-content would read every badge and initials as one noisy name.
5. **Scroll: the board container is every list's single scroll parent** (`overflow-auto`, both axes). Column `ScrollArea` removed; lists are plain elements. Columns stretch to the board's full content height (`min-h-full items-stretch`), so wherever the board is scrolled each list still has a visible drop area. No sticky column headers: dnd's keyboard jump-scroll ignores `scroll-padding`, so a sticky header would cover the focused card.
6. **Off-screen columns:** a keyboard drag can't scroll the board sideways (dnd limitation). The task dialog's **Column** select is the keyboard path to any column; no `scrollIntoView` hack.
7. **Custom announcements** with task/column titles and 1-based positions, built by pure functions in `lib/drag-announcements.ts`, plus `dragHandleUsageInstructions` that mention Enter-to-open.
8. **Theme toggle:** a small client wrapper passes `aria-label="Dark theme"` + `aria-pressed` (after mount, to avoid hydration mismatch). The generated component is untouched. `landing-header.tsx` keeps the old toggle (out of scope).
9. **User menu trigger** gets `aria-label="Account menu"` (it's in the navbar; its current name is the user's initials).
10. **Board cards on /boards:** link name = board title (`aria-labelledby`); role, task count and last update in an sr-only `aria-describedby` summary (the visible `NumberTicker` animates from 0, so it can't be the description).
11. **Task dialog:** static `htmlFor`/`id` pairs (`task-*`), matching `create-board-dialog.tsx`. Remove-label button: `type="button"`, `aria-label="Remove label <name>"`.
